Folders

Tick the folders to search. Removing one here deletes its index only — never your photos.

    Settings

    Accuracy and indexing time trade against each other. Changing the model means every folder has to be indexed again, so the choice is worth making deliberately.

    The app keeps running after you close the tab, so reopening is instant.

    Terminal

    The terminal works on the folder you are standing in. Searching across folders lives here in the app, where you can see the photos.

    ctximg
    Search the current folder. Offers to index it the first time.
    ctximg index
    Index or catch up this folder. --rebuild re-embeds everything.
    ctximg forget
    Delete this folder's index. Photos are untouched.
    ctximg web
    Open this folder here in the app.
    ctximg list
    Every folder indexed so far.
    ctximg doctor
    Python, torch, GPU, model and folders.

    At the ctximg prompt: :open 3 opens a result, :web brings the folder here, :reindex catches up, :q quits.

    Search by what a photo shows, not by what it is called. Nothing here matches filenames or keywords, so describe the scene the way you would to a person.
